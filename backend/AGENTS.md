# Backend AI instructions

This directory contains the Java backend service. Apply the repository-wide project rules in the parent AGENTS.md as well as these backend-specific expectations.

## Backend standards
- Prefer the simplest correct Spring/Java implementation.
- Do not add unnecessary abstractions, layers, or dependencies.
- Preserve existing APIs and contracts unless the user asks for a change.
- Validate correctness with the smallest relevant unit or integration checks.
- Keep controllers, services, and repositories focused and readable.

## Coding and design profile
- REA: clear and maintainable backend logic.
- Ponytail: practical implementation aligned with the current app structure.
- Hallmark: ensure output quality and reliability are consistent with the product standard.
- Impeccable: keep code clean, consistent, and easy to review.

Follow the same disciplined engineering rules described in the project root AGENTS.md.
